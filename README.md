# 每日习惯打卡

一个轻量的习惯打卡网站，帮助你每天记录想养成的习惯。

## 功能

- 添加自定义习惯
- 完成或取消今日打卡
- 查看今日完成数、完成率和最长连续天数
- 展示每个习惯最近 7 天的打卡记录
- 使用浏览器 `localStorage` 保存数据，无需后端服务

## 使用

直接在浏览器打开 `index.html` 即可使用。

## 在线访问

首次发布前，需要在仓库的 GitHub Pages 设置里把 Source 设为 GitHub Actions。之后每次更新 `main`，GitHub Pages 会自动发布网站。发布完成后访问：

```text
https://wfpepsi.github.io/black_tea/
```
